# ATS Resume Tracker

A simple application to analyze resumes for **ATS (Applicant Tracking System) compatibility**. It compares resumes with job descriptions and provides an ATS score and improvement suggestions.

## Features

* Resume upload (PDF/DOCX)
* ATS score calculation
* Keyword matching
* AI-based resume feedback

## Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Python, Flask
* AI: Google Gemini API

## How It Works

1. Upload resume
2. Add job description
3. Get ATS score and suggestions

## Setup

```bash
git clone https://github.com/your-username/ATS-Resume-Tracker.git
pip install -r requirements.txt
python app.py
```
